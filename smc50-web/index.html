¿Cómo consigo la API key? (forex / oro / índices)
  1. Entra a twelvedata.com → Get free API key y crea la cuenta (gratis).
  2. Copia tu API key y pégala arriba en API key TwelveData.
  3. Elige el símbolo igual que en Exness (XAUUSD, EURUSD, US30…) y pulsa Conectar.

La key se guarda solo en tu navegador (localStorage). El plan gratis da ~800 consultas/día: con actualización cada 20s (≈6/min) alcanza para unas 2 horas de uso al día por símbolo. Para cripto (BTCUSD, ETHUSD) no necesitas key: usa Binance.

¿Cómo la uso junto a Exness Terminal?
  1. Abre Exness Terminal en una pestaña del navegador y esta app en otra (o media pantalla cada una).
  2. Pon el mismo símbolo y temporalidad en ambas.
  3. Aquí ves las líneas L1-L4, el 50% y cada BOS/CHoCH; en Exness ejecutas tu operativa manual.

Exness Terminal no permite instalar indicadores personalizados, por eso esta app va al lado: misma lógica del EA v8.56, solo visual.
